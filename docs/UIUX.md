# UI/UX Specification

## Design Principles
- Minimal, clean, and modern.
- Messaging-first layout with a strong content area.
- Mobile-friendly navigation with a left drawer and back button.
- Clear visual hierarchy for chat list, active conversation, and message input.

## Layout Structure
- Header with logo, menu, notifications, and avatar.
- Sidebar with navigation and user summary.
- Chat list on the left for conversations.
- Main chat window for the active conversation.
- Bottom input bar for composing messages.

## Interaction Patterns
- Selecting a conversation highlights it in the chat list.
- Enter key sends a message when there is text.
- Mobile layout collapses the sidebar into an overlay sheet.
- Empty or loading states should be visually obvious.

## Accessibility Guidelines
- Buttons should have clear labels and visible focus states.
- Input fields should be keyboard accessible.
- Contrast and spacing should support readability.
